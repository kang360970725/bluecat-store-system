# 蓝猫门店运营系统 V2 功能架构

> 更新日期：2026-09-01
> 当前产品基线：先完整建设主体业务，再接入 X 管家数据；V1 数据不作为 V2 正确性的前置条件。

> 2026-09-01 补充：现有 `web-data-platform` 原始采集链路存在较多已知问题，不作为新系统可复用的数据来源。此前接通仅证明网络与任务调用可达，不代表数据正确；新采集系统须在主体业务完成后重新设计。

## 1. 建设原则

1. V2 使用独立数据表和领域模块，不依赖 V1 业务表拼装新页面。
2. 门店是经营管理主入口，资料、成本、投入、设备、员工、排班、评分和目标均可在单店工作台内查看。
3. 员工、排班、评分等同时保留跨门店管理入口，但不能割裂其门店归属。
4. 经营数据暂不以 V1 或手工结果填充。基础业务完成后再按数据合同接入 X 管家。
5. 桌面端与移动端共用响应式信息结构；前期只保持清晰、可用和一致，不做高成本视觉包装。

## 2. 一级功能模块

### 2.1 经营总览

集团和区域视角的门店状态、经营摘要、异常与待办。真实收入、利润和预测须等待 X 管家数据合同完成后接入。

### 2.2 门店中心

门店列表是经营档案入口。单店工作台固定包含：

- 经营概览：经营状态和核心指标摘要。
- 基础资料：主体、地址、营业日、面积、座位、租约等。
- 成本费用：固定、比例、公式、手工成本及生效版本。
- 投入回本：初始投入、追加投入、累计投入和回本测算。
- 区域设备：门店区域、设备资产、采购信息、换汰周期和升级估算。
- 员工岗位：在岗员工、岗位和任职关系。
- 排班排岗：班次模板、排班、调班和历史锁定。
- 评分业绩：门店/员工评分、目标及业绩展示。

### 2.3 员工中心

跨门店员工名册、入转调离时间线、账号状态、岗位和门店归属。员工登录账号与员工档案一对零或一，避免所有员工被强制创建账号。

### 2.4 排班管理

系统班次模板、门店班次、排班计划、员工排岗、临时调班和已结束班次锁定。业绩归属于班次，人员变动不得改写历史班次事实。

### 2.5 目标与评分

评分方案、评分维度、员工综合评分、月度目标、日/班次拆分和预测。规则必须版本化，后续同步数据只能提供事实，不能改写目标。

### 2.6 系统配置

默认岗位模板、成本项模板、班次模板、设备类别与换汰建议、评分模板、角色权限及数据范围。

### 2.7 数据中心（后置）

X 管家连接、采集状态、原始记录、标准事件、规则版本、对账与补采。等主体业务模型稳定后再优化爬虫和接入真实数据。

## 3. 数据模型决策

### 3.1 继续使用

- `v2_organizations`、`v2_stores`
- `v2_position_templates`、`v2_store_positions`
- `v2_employees`、`v2_employments`、`v2_employment_histories`、`v2_employee_leaves`
- `v2_store_operating_profiles`
- `v2_cost_item_templates`、`v2_store_cost_configs`
- `v2_store_investments`、`v2_store_assets`
- 已建立的数据平台原始记录、事件、规则、事实和对账表

### 3.2 本轮纠正

- 新增 `v2_store_areas`，设备通过 `area_id` 归属具体门店区域。
- 新增独立的 `v2_accounts`、`v2_roles`、`v2_permissions` 及账号角色、角色权限、门店数据范围关系表。
- V2 账号可关联员工，但不与员工强制绑定；数据范围支持全部门店、指定门店和员工当前门店。

### 3.3 后续新增

- 班次模板、门店班次、排班计划、排班明细和调班记录。
- 评分方案、评分规则版本、评分结果与明细。
- 经营目标、目标版本、日/班次拆分和锁定事实。
- 月度经营快照、成本计算明细、利润预测和回本快照。
- 设备市场参考价、询价批次和升级方案。

## 4. 实施顺序

1. 在不影响现有业务表的前提下，重新设计并实现 X 管家采集系统。
2. 权限和门店数据范围在所有新接口上的强制过滤。
3. 员工剩余闭环。
4. 排班批量操作、冲突校验和自动锁定。
5. 门店成本、投入、盈亏和回本。
6. 经营目标拆分与动态重算。
7. 设备升级管理。
8. 系统工作台。
9. 员工评分方案暂缓。

X 管家详细协作方式、证据包和验收标准见 `docs/v2-x-manager-integration-plan.md`。

每一阶段先在本地完成迁移、校验和业务验收；生产部署由用户明确确认后执行。
